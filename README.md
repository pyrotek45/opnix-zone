# Opnix Zone

A modular, fully procedural shooter toolkit in pure Rust (Bevy 0.16), and the
games built from it. There are no asset files anywhere in this repository:
every model, map, sky and sound is generated by code.

| Game | What it is |
|------|------------|
| **Ember Atoll** (`games/ember_atoll`) | Co-op defense. Mine and automate the islands by day, hold the beacon against robotic sea creatures by night. Also includes a pure **Horde** mode. |
| **Iron Town** (`games/iron_town`) | Tactical robot shooter in a procedural town of enterable buildings: team deathmatch, scavenge, ranked and terrorist hunt, 1v1 to 6v6 with bots in every empty slot. Hold-to-cover with blind fire and vaulting, kill-cams, an armory of five classes with a live 3D gunsmith, shootable killstreak aircraft and a career of unlocks. |

Both games are thin: a content catalog, rules, and a small director. Movement,
weapons, AI, bots, networking, rendering, menus and audio are shared crates.

## Run

```bash
cargo run --release -p ember_atoll
```

```bash
cargo run --release -p iron_town
```

Always use `--release` to play; debug builds are much slower. Linux needs the
usual Bevy system packages (ALSA, udev, X11 or Wayland, Vulkan); `shell.nix`
provides them on Nix. Add `--no-default-features` to build without audio.

Shortcuts past the menu: `--solo`, `--host`, `--join ADDRESS`, `--mode N`,
`--seed N`, `--teams N`. **MODEL VIEWER** in the main menu shows every
operator pose side by side.

## Playing online (no server, no VPN, no port forwarding)

One player picks **HOST GAME** and plays too. The lobby shows a **join code**
like `K7Q-4MZ`. Friends pick **JOIN GAME**, type the code, and connect.

* **Over the internet:** the code is all anyone needs. Behind the scenes both
  games ask a public STUN server what their internet address is, swap
  addresses through a free public message board (ntfy.sh) under that code,
  and then send packets straight at each other. That "hole punching" opens
  both home routers, so no ports have to be forwarded and nobody needs
  Hamachi or another VPN. Game traffic goes directly between players; the
  board only ever sees addresses. The host also asks the router for a UPnP
  port (UDP 27650) as a second way in.
* **Same network (LAN):** the host shows up under *Games on your network* on
  the Join screen - click it.
* **By address:** the Join field also takes an IP (or `ip:port`).

Hole punching works with almost every home router. It cannot get through
"symmetric" NATs (some mobile hotspots and office networks); if both players
are on one of those, someone needs a forwarded UDP port or a VPN. To use your
own ntfy-compatible board instead of ntfy.sh, set `OPNIX_BOARD` (for example
`OPNIX_BOARD=https://ntfy.example.org`).

What makes it play well online:

* **Lag compensation.** Other players are shown 0.1 s in the past from a
  buffer (smooth even with jitter), and every input tells the host what
  moment you were looking at. When you fire, the host rewinds everyone to
  that moment (up to 0.35 s) before checking the hit: if it was on your
  screen, it hits. In co-op the sea creatures are rewound the same way.
* **Instant shooting.** Your own recoil, muzzle flash, sound, tracer and ammo
  count happen immediately on your machine; the host confirms in the
  background. Rockets and thrown gear leave your hand at once too. Quick taps
  between network sends are never lost, and weapon swaps show at once.
* **UDP with two lanes.** Commands and effects are reliable and ordered
  (selective acks, round-trip-based resends); snapshots and pings are
  latest-only, so a lost packet never holds up newer ones. Tested with 30%
  packet loss.
* **Clean failures.** Ping is on the scoreboard (and in the corner with
  *FPS / PING* on). Silent connections time out on both sides, and you are
  told why you were disconnected.
* **Reconnecting.** If your connection drops, the game retries the host on
  its own (and leaves a RECONNECT button if that fails). The host keeps your
  seat for ten minutes: you come back on the same team with your score,
  class and weapons.
* **Players:** name tags over teammates, enemy names under your crosshair,
  text chat (**T**), a kill-cam on your killer while you wait to respawn,
  spawn protection, spawns away from the enemy, duplicate names told apart,
  and everyone sees each other's real attachments.

Headless dedicated servers are included too, for running a match on a spare
machine. They print their join code on start. The Iron Town one starts each match on its own after a short lobby:

```bash
cargo run --release -p iron_town --bin iron_server -- --teams 4 --score 30
```

```bash
cargo run --release -p ember_atoll --bin ember_server -- --mode 0 --port 27650
```

Press **V** in a match (or launch with `--spectate`) to watch other players
over the shoulder; the camera cuts to whoever is in a firefight. Press **B**
while spectating (or launch with `--spectate-fp`) to watch through their own
eyes instead: their gun, recoil, aiming, reloads and HUD.

## Downloads and builds

Ready-to-run builds come from the **Release builds** workflow
(`.github/workflows/release.yml`): run it from the Actions tab, or push a
`v*` tag to publish a release. It produces:

* `IronTown-x86_64.AppImage` / `EmberAtoll-x86_64.AppImage` - Linux: make it
  executable (`chmod +x`) and run it. `./IronTown-x86_64.AppImage server`
  starts the dedicated server instead. Built against glibc 2.31, so they run
  on any desktop distro from about 2020 on (Ubuntu 20.04+, Debian 11+,
  Fedora 32+, SteamOS). If FUSE is missing, run with
  `APPIMAGE_EXTRACT_AND_RUN=1`.
* `IronTown.exe` / `EmberAtoll.exe` - Windows, a single file each, plus
  `*-windows.zip` with the game and its dedicated server.

To build them yourself: `packaging/build-appimage.sh` (Linux) and
`packaging/build-windows.sh` (cross-compiles the Windows builds from Linux
with MinGW). Everything is generated in code, so each game is one file with
no asset folder to ship.

## Controls

| Action | Keyboard / mouse | Gamepad |
|--------|------------------|---------|
| Move / look | WASD / mouse | left / right stick |
| Fire / aim | LMB / RMB | RT / LT |
| Reload / use | R / F | X |
| Jump / vault | Space | A, or X in front of something low |
| Sprint | Shift | click left stick |
| Crouch / prone | C (tap crouch, hold prone), Z prone | B (tap / hold) |
| Stabilize scope | Shift while scoped | click left stick while scoped |
| Melee | E | click right stick |
| Weapons | 1-9, wheel | Y |
| Take / leave cover | Q | LB |
| Gear: cook / throw / pin back | hold G, release / R | hold RB, release / X |
| Call in killstreak (newest first) | X | D-pad right |
| Inspect weapon | I | D-pad up |
| Night vision | N | D-pad left |
| Suppressor on / off | U | tap D-pad down |
| Flashlight | H | hold D-pad down |
| Armory / scoreboard (Iron Town) | L / hold Tab | pause menu / hold Back |
| Chat / spectate | T / V | - |
| Pause / back | Esc | Start / B |
| Menus | mouse, or arrows + Enter | D-pad or stick + A, LB / RB for tabs |

Menus move focus in the direction you press: left / right walks along a
row of buttons, up / down between rows; on a value (team size, an
attachment) left / right changes it.

**Crouch and prone** never flicker however long you hold the button: from
standing a press crouches at once and holding on goes prone; from a crouch a
tap stands you up and a hold goes prone; from prone a tap crouches and a hold
stands.

Every keyboard and mouse binding can be changed in **SETTINGS > CONTROLS**:
pick an action, press the new key. A key already in use swaps places.

Stations are walk-up terminals: stand next to one, press **Use**, and a window
opens. Everything in it can be clicked or navigated with a pad.

## Cover, vaulting, melee and grenades (Iron Town)

**Cover** works like the third-person cover shooters: press **Q** (LB) facing a
wall or crate to snap onto it, back to the wall, with the camera over your
shoulder; press it again (or pull away from the wall) to snap off. Aiming or
firing turns you out from the wall to face the shot. Left / right moves along it and stops at
the edge; behind low cover you crouch. **Aim** to pop up over low cover or
lean out round a corner in first person. **Fire without aiming** to blind
fire: only the gun goes over the top or round the corner - your head stays
safe, your aim does not. Whatever you show of yourself can be hit.

**Vaulting**: jump at anything waist to chest high - low walls, barriers,
crates, window sills - and you go over it (or up onto it). Jump behind low
cover to vault it. Going through a closed window takes the glass with you.

**Melee** (E / R3): a gun-butt strike that drops a standard robot.

**Grenades cook**: holding the gear button pulls the pin and the fuse starts
burning; let go to throw with what is left of it (a meter shows it), press
reload to put the pin back. Hold a frag too long and it goes off in your hand.
You see your arm wind up and throw; others see you do it too.

**Scopes sway**; crouching and going prone steady them, and **stabilize**
(Shift / L3) locks the robot's servos: the sway slows to a stop right where it
is (the crosshair never jumps) for 2.5 s standing, 4 s crouched, 6 s prone,
then needs a moment to recover.

**Hip fire is a spray** and opens up as you move: walking nearly doubles the
cone, sprinting triples it, in the air it is worse; the crosshair shows the
real cone. The Tactical Laser and Steady Hands tighten it. Rounds fly until
they hit something; past a gun's effective range they lose punch (to 55% at
three times it), and shotguns reach far but spread too wide to matter.

**Kill-cam**: when someone takes you down, the last few seconds replay from
over their shoulder - their moves, the tracers, the killing shot in slow
motion. Jump / (A) skips it.

**Explosions** are big: frags reach 10 m, rockets 9 m. Shot-up cars and
barrels smoke, catch fire and blow a few seconds later - and can set each
other off.

**Killstreaks** - kills without dying earn rewards. Each class picks up to
three in the armory; bigger ones need longer streaks. Earned rewards wait on
a stack of three shown above your ammo (a fourth pushes the oldest off), and
calling one in (**X** / D-pad right) uses the newest first.

| Kills | Reward | |
|------:|--------|---|
| 3 | Recon UAV | a radar plane circles the town: every enemy shows on your team's radar for 30 s |
| 4 | Supply drop | your whole team healed and rearmed, gear included |
| 5 | Airstrike | a jet flies over where you aim and drops a line of bombs |
| 7 | Attack drone | hovers above you for 30 s and shoots enemies it can see |
| 9 | Artillery barrage | shells rain down around where you aim |

Aircraft are real: the radar plane, the jet and the drone fly over the map,
and the other team can **shoot them down** (bullets or rockets) - a downed
jet drops nothing more, a downed radar plane takes the UAV with it. Enemy
call-ins are announced ("ENEMY RADAR PLANE SPOTTED - SHOOT IT DOWN",
"INCOMING ARTILLERY - GET INDOORS"). Bots call in theirs as well.

**The town changes as you fight.** Doors open and close (walk up and press
Use; bots shoulder through them) and can be shot or blown off their hinges.
Window glass shatters when a round or a blast goes through it. Street
clutter - bins, benches, mailboxes, crate stacks, parked cars and red
barrels - is cover until it is shot apart; barrels and cars explode and can
set each other off. Bullet holes, scorch marks, rubble and robot wreckage
stay where they fall. Ladders lead up to the roofs.

**Juice:** medal banners that slam onto the screen (double / triple kill,
headshot, revenge, first blood), a headshot ding, killstreak fanfares, a
little zoom punch on every kill, robots bursting into sparks and plates when
they go down, jets with doppler roar, and a heartbeat when you are nearly dead.

Gear, one kind per class:

| Gear | What it does |
|------|--------------|
| Frag grenade | Thrown explosive on a short fuse |
| Smoke grenade | A cloud that blocks sight: bots cannot see through it and name tags vanish behind it |
| Flashbang | Whites out the screen of anyone who sees it go off (worse looking straight at it); bots are stunned |
| Proximity mine | Thrown, arms after a second, goes off when an enemy comes close |
| Throwing knife | Fast and silent, deadly on a direct hit |
| Stim | Heals and puts out fire |
| Ammo pack | Refills reserve ammo for you and nearby teammates |

Perks: Lightweight, Plate Carrier, Fast Hands, Deadeye, Scavenger (kills refill
a magazine), Ghost (never on radar), Flak Jacket (less explosive damage),
Quick Draw (faster aiming and swaps), Steady Hands (tighter hip fire),
Thermal Optics (enemies glow hot while you aim, even through smoke) and Night
Vision (a green visor for night maps, toggled with **N** / D-pad left).

**Match settings** (host, in the lobby): time of day - day, dusk, night or a
full day/night cycle - and weather - the map's own, clear, overcast, rain, fog
or random fronts that roll through mid-match. Robots carry flashlights at
night.

**Maps:** pick a **LAYOUT** in the main menu (or `--map crossroads` /
`--map dockyard`). *Random Town* is freshly generated every match; the fixed
maps are the same every time so you can learn them:

* **Crossroads** - two main streets crossing at a fountain plaza, with
  three-lane flanks through back alleys and courtyards and a three-storey
  tower overlooking mid.
* **Dockyard** - a big open-ended warehouse in the middle, stacked shipping
  container lanes either side and two-storey offices at each base.

## Modes (Iron Town)

* **Team deathmatch** - two squads, bots in every empty seat, first to the
  score limit. Use any gun and any part.
* **Scavenge** - everyone spawns with a pistol and a spare magazine. Guns
  (with whatever parts they come with), ammo, gear and armour lie around the
  town and come back after a while; whoever goes down drops their gun and
  some ammo. Walk over loot to take it; with both hands full, Use swaps the
  gun you hold.
* **Ranked team deathmatch** - the same fight for rank points (bronze to
  diamond), played with what your career has unlocked.
* **Terrorist hunt** - your squad (friends, bots for any empty seat) against
  a town full of hostiles holding posts. They see in a cone, notice standing
  figures further than crouched or prone ones, and **listen**: unsuppressed
  gunfire carries 80 m, suppressed shots 9 m, sprinting footsteps 15 m,
  walking 7 m, a body falling 12 m, pushing through a bush 18 m. They come to
  look, call out what they see to each other, and fire back at gunshots
  they hear. They never respawn; the squad shares five lives. Clear the town
  to win.

## The armory and your career

You have **five classes**. The armory shows one thing at a time: pick a
class, then a slot (primary, secondary, perk, gear, killstreaks), then what
goes in it - and for a gun, its attachments, with left / right stepping
through the parts that fit while the gun turns on the stage and the stat
bars show what changes. B / Esc goes back up a level. Classes are saved,
are edited in the lobby, and during a match can only be **switched** (L /
D-pad down): the new one applies on your next spawn.

Your **career** is kept on this machine: experience from kills, headshots
and wins raises your level, levels unlock guns, and kills with a gun unlock
its attachments slot by slot. Unlocks only bind in **ranked**; every other
mode keeps everything open.

## Maps and cover

Maps are built around the cover system and a robot's size: low walls,
street barriers, rooftop parapets and window sills are all 1.15-1.2 m - a
crouching robot is hidden behind them, and they are low enough to vault.
Anything you could take cover behind is solid; thin things (poles, pipes,
wires, lamp posts) and bushes you walk through - and bushes shake and
rustle loudly when anyone does. A test walks every standable spot of every
map to make sure nothing solid-looking can be walked into.

The minimap draws the town from above - buildings, walls, low cover, team
bases and ladders - north up, with your arrow turning as you look.

## Look and sound

The typeface (Opnix Pixel) is drawn in code like everything else and built
into a TrueType font when the game starts. If [Piper](https://github.com/rhasspy/piper)
and a voice model are installed (`piper` on the `PATH` or `OPNIX_PIPER`, and
`OPNIX_PIPER_MODEL` or an `.onnx` file in the config folder's `voice/`), an
announcer reads the callouts aloud; nothing is shipped or downloaded.

## Weapons

Guns are built from parts. Each weapon is a frame (receiver, barrel, bore,
magazine shape, stock) plus numbers, and seven slots change both its stats
and its geometry: **optic, muzzle, barrel, underbarrel, magazine, stock and
ammunition**. Parts are limited by weapon class (no sniper scope on a
shotgun), and ammo depends on caliber: hollow point, armor piercing (punches
through thin walls), incendiary (burns), explosive rounds, slugs, dragon's
breath, flechettes, thermobaric and napalm rockets, overcharged cells.

Actions and reloads are animated per weapon: magazines drop and slap home,
shotguns load shell by shell (fire to interrupt), bolts and pumps are worked
after each shot, pistol slides kick, belt-fed guns tilt up to reload. Optics
with magnification (ACOG, sniper scope) switch to a scope overlay with sway
that crouching, going prone or holding your breath steadies. A suppressor
keeps you off the enemy radar; unsuppressed fire shows you on it.

## Performance

The engine is built for weak hardware:

* The world renders to a low-resolution target (window size / **PIXEL SIZE**)
  and is scaled up, so the GPU shades a fraction of the pixels. Raising pixel
  size in Settings is the biggest frame-rate lever; shadows can be turned off.
* Every model is baked into a few vertex-coloured meshes that share two
  materials, so hordes batch into a handful of instanced draws.
* Terrain is chunked, props are merged per region, particles are capped.
* The simulation uses a spatial grid and staggered AI. The headless stress
  test runs 1,500 enemies in about 2 ms per frame (dev profile).
* Network snapshots are 17 bytes per entity at 20 Hz (10 Hz in huge battles).
* Static collision (every wall, stair and prop) lives in a bucketed grid, and
  bots share a small per-frame pathfinding budget.
* While a menu shows the 3D showroom, the world camera is switched off.

## Tests

```bash
cargo test --workspace
```

The suite runs the real simulation headlessly, including full matches over
real sockets (host + client), bot matches, mining, purchases and a stress test.

`games/iron_town/tests/soak.rs` plays full bot matches on random towns and
both fixed maps, with one seat driven by a "chaos monkey" (random running,
jumping, stance changes, leaning and shooting), and checks every tick that
nobody is inside a wall, under the ground, out of bounds, stuck in the air or
teleporting, and that no shot reaches anyone through a wall. Run it long:

```bash
SOAK_SECONDS=600 SOAK_SEEDS=1,2,3,4,5,6,7,8 cargo test --release -p iron_town --test soak -- --nocapture
```
